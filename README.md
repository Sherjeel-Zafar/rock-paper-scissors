# Rock Paper Scissors 🎮

A simple Rock Paper Scissors game built with **HTML, CSS, and JavaScript**.

## How to Play
- Open `index.html` in your browser
- Choose Rock, Paper, or Scissors
- Computer makes its choice
- See who wins!

## Project Files
- `index.html` → main game page
- `style.css` → styling
- `script.js` → game logic
